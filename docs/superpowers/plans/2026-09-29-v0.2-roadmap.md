# autotyper v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make autotyper comfortable to use while recording (fit a duration, live progress, start on a key, resume, live preview), more realistic (protected spans, Spanish-style typos, word deletion), more robust (hotkey permission check, default profile, window-title guard), and ship it as v0.2.0 on GitHub and Homebrew.

**Architecture:** Every feature keeps the split between the pure, seeded planner (`model.py`) and the runner/CLI adapters. New behaviour lands as new `TypingConfig` fields or CLI-only flags, new `Event` kinds, and small pure helpers with unit tests. Two adapters gain macOS calls (`focus.py`), always with `None` fallbacks so tests never touch the OS.

**Tech Stack:** Python 3.12+, uv, pynput, pyyaml, pyobjc (Cocoa, ApplicationServices), ctypes for IOKit, pytest. Demo recording with asciinema + agg.

**Spec:** `docs/superpowers/specs/2026-09-22-autotyper-design.md` (v0.1 baseline). This plan is the spec for v0.2: each task states the behaviour it adds.

## Global Constraints

- Commit style: one line, conventional prefix, no body, no trailers, specific `git add` paths (see `.claude/agents/git-commiter.md`, ignored by git).
- Everything user-facing in English: code, CLI text, docs, changelog.
- Invariant from v0.1 still holds: with `uncorrected_rate = 0`, `replay(plan(text))` equals the text. Every planner task must keep `test_plan_with_errors_still_reproduces_text_when_all_corrected` green.
- Never run the real injector from an automated session. Verify with pytest fakes, `--dry-run` or `--dry-run --live`.
- Run the whole suite (`uv run pytest -q`) before every commit.
- Order: phases can be done in any order, but tasks inside a phase are sequential. Task 12 changes the `run()` signature; do it after Task 3.

```python
"""Pick a typing speed so the whole text takes a target number of seconds."""

from __future__ import annotations

import random
from dataclasses import replace

from autotyper.config import TypingConfig
from autotyper.events import Event
from autotyper.model import plan

_MIN_CPS = 0.5
_MAX_CPS = 40.0


def fit_duration(
    text: str, config: TypingConfig, seed: int, target_s: float, rounds: int = 3
) -> tuple[list[Event], float]:
    """Re-plan a few times, scaling cps by measured/target, since pauses do not scale."""
    if target_s <= 0:
        raise ValueError("duration must be > 0")
    cps = config.cps
    events: list[Event] = []
    for _ in range(rounds):
        events = plan(text, replace(config, cps=cps), random.Random(seed))
        total_s = sum(e.delay_ms for e in events) / 1000
        if total_s <= 0:
            break
        cps = min(_MAX_CPS, max(_MIN_CPS, cps * total_s / target_s))
    events = plan(text, replace(config, cps=cps), random.Random(seed))
    return events, cps
```

```python
class TerminalInjector:
    """Dry-run back end: renders keys to a text stream in real time."""

    def __init__(self, out: TextIO = sys.stdout) -> None:
        self._out = out
        self.buffer = ""

    def press(self, key: str, hold_s: float) -> None:
        if key == BACKSPACE:
            if self.buffer and self.buffer[-1] not in "\n\t":
                self._out.write("\b \b")
            self.buffer = self.buffer[:-1]
        elif key == ENTER:
            self._out.write("\n")
            self.buffer += "\n"
        elif key == TAB:
            self._out.write("\t")
            self.buffer += "\t"
        else:
            self._out.write(key)
            self.buffer += key
        self._out.flush()
```

import re

_PROTECTED = re.compile(
    r"https?://\S+"          # URLs
    r"|www\.\S+"
    r"|[\w.+-]+@[\w-]+\.[\w.-]+"  # emails
    r"|`[^`\n]*`"            # inline code

def protected_mask(text: str) -> list[bool]:

    return mask

```python
import ctypes

_LISTEN_EVENT = 1  # kIOHIDRequestTypeListenEvent


def _iokit():
    try:
        lib = ctypes.cdll.LoadLibrary("/System/Library/Frameworks/IOKit.framework/IOKit")
    except OSError:
        return None
    lib.IOHIDCheckAccess.restype = ctypes.c_uint32
    lib.IOHIDCheckAccess.argtypes = [ctypes.c_uint32]
    lib.IOHIDRequestAccess.restype = ctypes.c_bool
    lib.IOHIDRequestAccess.argtypes = [ctypes.c_uint32]
    return lib


def input_monitoring_granted() -> bool | None:
    """True/False for the Input Monitoring permission, None if undetermined or unavailable."""
    lib = _iokit()
    if lib is None:
        return None
    code = lib.IOHIDCheckAccess(_LISTEN_EVENT)
    return {0: True, 1: False}.get(code)


def request_input_monitoring() -> None:
    lib = _iokit()
    if lib is not None:
        lib.IOHIDRequestAccess(_LISTEN_EVENT)

def frontmost_window_title() -> str | None:
    """Title of the focused window of the frontmost app, or None if unavailable."""
    try:
        from AppKit import NSWorkspace
        from ApplicationServices import (
            AXUIElementCopyAttributeValue,
            AXUIElementCreateApplication,
            kAXFocusedWindowAttribute,
            kAXTitleAttribute,
        )
    except ImportError:
        return None
    app = NSWorkspace.sharedWorkspace().frontmostApplication()
    if app is None:
        return None
    err, window = AXUIElementCopyAttributeValue(
        AXUIElementCreateApplication(app.processIdentifier()), kAXFocusedWindowAttribute, None
    )
    if err != 0 or window is None:
        return None
    err, title = AXUIElementCopyAttributeValue(window, kAXTitleAttribute, None)
    return str(title) if err == 0 and title is not None else None
```
